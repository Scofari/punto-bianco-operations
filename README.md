# Punto Bianco Operations

Internal patient-visit coordination assessment. Romanian interface, seven staff roles, PostgreSQL persistence, Supabase Auth, Next.js and TypeScript.

## Implementation milestones

1. Repository, deployment foundation and database schema.
2. Authentication, authorization and transactional visit workflows.
3. Responsive role workspaces, registration, reservations and transfer calendar.
4. Integration tests, browser verification and submission documentation.

Only invented patient data is permitted. Never commit credentials, database URLs, personal data or trial fonts.

Work began on 2026-11-03. Actual implementation and verification time is recorded in docs/AI-WORKLOG.md.
